How to play & how points work

Flag → Capital

Only a country's flag is shown — never its name. Figure out the country from the flag, then comment the name of its capital city.

  • Rookie — well-known countries, 10 pts, 3 hints available.
  • Explorer — moderately known, 20 pts, 2 hints available.
  • Globetrotter — tricky ones, 30 pts, 2 hints available.

Each hint you reveal lowers the round's value slightly — first correct comment the host sees wins the round. Type that viewer's name in the box and tap Award to log it.

Gifts: a gift doesn't hand any one viewer an advantage. Instead it unlocks one shared boost for the whole chat — like an extra letter reveal — so it helps everyone equally.

Test Mode runs the exact same game without saving anything to the scoreboards, so you can rehearse freely before going live.
